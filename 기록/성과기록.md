# 성과 기록

성과리뷰팀이 업로드 후 한 줄씩 **추가**합니다. 기존 줄은 지우지 않습니다.

| 날짜 | 제목 | 형식 | 조회 | 평균시청% | 구독+ | 유입 1위 | 잘된 이유 | 재사용할 요소 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |

## 쓰는 법

- **`구독+` 는 비워두지 마세요.** 이 채널의 핵심 지표입니다. 조회수만 적힌 줄은 성과리뷰팀 기준 ②번 위반입니다.
- 숫자는 **유튜브 스튜디오에서 직접 본 것만** 적습니다. 모르면 빈칸. 추측 금지.
- `형식` 은 `롱폼` / `쇼츠` 로 구분합니다. 둘은 역할이 달라서 섞어 보면 판단이 흐려집니다.
- `잘된 이유` 는 한 줄. "반응이 좋았다" ❌ → "썸네일 색이 기존 영상들과 같은 계열이라 채널 인식됨" ✅

## 언제 되돌아보나

**업로드 10개마다** 브랜드 분석팀을 부르세요. 로파이는 한 영상의 성적보다 **누적 패턴**이 중요합니다.

```
/dept 브랜드 분석팀 기록/성과기록.md 최근 10개를 보고 구독이 붙은 3개·안 붙은 3개를 뽑아줘
```

## 쇼츠와 롱폼을 나눠 보는 이유

| | 봐야 할 숫자 | 실패 신호 |
| --- | --- | --- |
| 쇼츠 | 구독+ , 조회 | 조회는 터졌는데 구독+ 가 0 → 훅만 좋고 채널 매력이 안 전달됨 |
| 롱폼 | 평균시청% , 구독+ | 평균시청%가 낮음 → 무드가 중간에 깨졌거나 루프 이음새 문제 |
