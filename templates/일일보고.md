# 일일 보고 빈 양식 (비서실)

`기록/일일보고/YYYY-MM-DD.md` 로 복사해서 씁니다.

```
# YYYY-MM-DD 일일 보고

📌 오늘 대표가 결정할 것 : n개
  1.

📋 부서별 한 줄
  시장조사팀
  기획 1팀
  검수팀
  기획 2팀
  영상 제작팀
  이미지 제작팀
  성과리뷰팀

⛔ 미실행
  - 유튜브 업로드·예약 : 안전규칙 ②로 사람이 직접

⚠️ 라이선스 대표 확인 필요
  -
```

## 규칙

- 부서당 **2줄 넘기지 않기.** 넘으면 비서실 기준 위반입니다.
- 결정할 항목은 **맨 위**에. 대표는 이 줄만 보고 하루를 시작합니다.
- 실제로 안 된 일은 반드시 `⛔ 미실행` 에. "완료"라고 쓰면 안전규칙 ⑤ 위반입니다.
- **유튜브 업로드·예약은 언제나 `⛔ 미실행`** 입니다. 사람이 하는 일이라 비워둘 일이 없습니다.
- 라이선스 확인이 필요한 소재는 마지막 칸에 모읍니다. 여기 쌓인 채로 제작에 들어가면 안 됩니다.
