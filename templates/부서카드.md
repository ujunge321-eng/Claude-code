# 부서 카드 빈 양식

새 부서를 만들 때 아래를 복사해서 `AI_COMPANY.md` 아래쪽에 붙여넣으세요.

```
부서 이름:
오늘 할 일:
지켜야 할 기준:
  ①
  ②
  ③
결과물 형태:
넘겨줄 다음 부서:
```

---

## 쓸 때 딱 3개만 확인하세요

**1. 기준 3줄이 "반려 기준"인가?**

| ❌ 이건 기준이 아님 | ✅ 이게 기준 |
| --- | --- |
| 좋은 컨셉을 내줘 | 무드를 한 장면으로 못 그리면 탈락 |
| 내 채널 톤에 맞게 써줘 | 금칙어가 제목에 있으면 탈락 |
| 저작권 조심해줘 | 라이선스 출처 한 줄이 없으면 탈락 |
| 겹치지 않게 해줘 | 최근 30일 업로드와 무드 키워드 2개 이상 겹치면 탈락 |

**"X면 탈락"** 형태로 안 적히면, 그 부서는 아직 만든 게 아닙니다.

**2. 결과물 형태가 눈에 그려지는가?**

"보고서" ❌ → "레퍼런스 5개 (링크 / 조회수·업로드일 / 무드 키워드 3개 / 따라할 요소 1개)" ✅
개수·형식·항목까지 적으세요.

**3. 다음 부서가 정해졌는가?**

넘길 곳이 없으면 `(없음 · 대표에게 직접)` 이라고 적으세요.
아무 데도 안 넘어가고 아무도 안 부르는 부서라면 — 그 부서는 지우는 게 맞습니다.

## 채워진 예시

```
부서 이름: 브랜드 검수팀(QA)
오늘 할 일: 기획팀이 낸 아이디어 10개를 저작권·브랜드 기준으로 검사
지켜야 할 기준:
  ① 음원·영상·이미지 라이선스 출처가 한 줄로 안 적히면 탈락
  ② 금칙어가 제목·설명에 있으면 탈락 (예: "chill vibes only", "감성 가득")
  ③ 최근 30일 업로드와 무드 키워드가 2개 이상 겹치면 탈락
결과물 형태: 통과 O / 반려 X + 반려 사유 한 줄
넘겨줄 다음 부서: 기획 2팀(제작 사양서)
```

## 이 채널에서 부서를 새로 만들 만한 경우

지금 12개로 안 잡히는 일이 생겼을 때만 만드세요. 예를 들면:

| 상황 | 만들 만한 부서 | 기준 3줄의 방향 |
| --- | --- | --- |
| 음원을 직접 만들기 시작 | 작곡팀 | BPM 범위 밖이면 탈락 / 루프 안 되면 탈락 / 레퍼런스와 70% 이상 유사하면 탈락 |
| 재생목록이 20개 넘어감 | 큐레이션팀 | 무드 겹치는 재생목록은 통합 / 영상 5개 미만 목록은 탈락 |
| 댓글이 많아짐 | 커뮤니티팀 | 실제 답글 작성 금지(초안까지) / 정해진 답변 톤 벗어나면 탈락 |

만들기 전에 한 번 더 생각해보세요. **2주 안에 세 번 이상 부를 일이 아니면, 안 만드는 게 맞습니다.**
