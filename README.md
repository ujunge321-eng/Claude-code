## 시작하기

### STEP 0. 남은 칸 하나

`AI_COMPANY.md` 0장의 **채널 링크**만 비어 있습니다. (확인이 안 돼서 `미확인` 으로 뒀습니다)

YouTube Studio → `설정` → `채널` → `고급 설정` 에서 채널 ID를 보거나,
채널 페이지 `공유` → `채널 링크 복사`. 핸들을 만드셨으면 `youtube.com/@핸들` 입니다.

나머지 숫자(쇼츠 60초, 썸네일 4단어, 롱폼 45분~1시간 등)는 **기본값**입니다.
그냥 쓰시다가 안 맞으면 그때 바꾸세요.

### STEP 1. 오늘 바로 해보기

이 폴더에서 `claude` 를 실행하고 한 줄만 치세요.

```
/today
```

조사 → 컨셉 10개 → 검수까지 돌고 **TOP 3만 보고하고 멈춥니다.**
트랙 구성표는 대표님이 1개를 고른 뒤에 씁니다. 이게 이 구조의 핵심이에요.

### STEP 2. 고른 다음

```
2번으로 갈게. 기획 2팀 불러서 트랙 구성표랑 제목·설명·태그 만들어줘
```

## 이 채널에 맞게 바꾼 것 5가지

가이드 원본은 인스타 정보 콘텐츠 기준이라, 로파이 채널에 맞게 아래를 손봤습니다.

**1. 점수 배점을 구독 쪽으로 몰았습니다**
핵심 지표가 구독자라서, 기획 1팀 10점 중 **구독 유발에 4점**을 줬습니다. 조회수는 배점에 없습니다.

**2. 저작권 게이트를 따로 만들었습니다** (사규 2장)
로파이 채널이 죽는 건 대부분 여기입니다. 검수팀 반려 기준 **①번이 라이선스**고, AI는 "써도 된다"고 단정하지 못하게 막아뒀습니다. 판단은 대표님이 합니다.

**3. 제목 반려 테스트를 넣었습니다** (대표님이 지정하신 기준)

```
제목에서 장르어와 분위기어를 다 지운다. 남는 게 없으면 → 탈락.
```

| 제목 | 지우면 남는 것 | 판정 |
| --- | --- | --- |
| Hiphop lofi | (없음) | ❌ |
| Summer lofi playlist | (없음) | ❌ |
| 3AM convenience store, rain outside | 새벽 3시 · 편의점 · 창밖 비 | ✅ |

`playlist` · `mix` · `relaxing` · `chill` 같은 말투도 전부 여기서 걸립니다.
장르는 제목이 아니라 **태그와 설명란**에서 처리합니다.

**4. 참고 채널 대역을 44명 기준으로 잡았습니다**

| 대역 | 따라해도 되나 |
| --- | --- |
| **100 ~ 3,000** | ✅ 주 참고 대역 — 5개 중 3개 이상 여기서 |
| 1만 ~ 5만 | ⚠️ 채널 정리 방식만. 개별 영상은 안 따라함 |
| 10만 이상 | ❌ 성공 요인이 "이미 크다"라서 재현 불가 |

구독자 500명 되면 `1,000~2만` 으로 올리세요.

**5. 쇼츠와 롱폼의 역할을 나눴습니다**
쇼츠 = 발견(구독 유입) / 롱폼 = 정착(구독 유지). 성과 기록도 따로 봅니다.
쇼츠 첫 2초는 자막이 아니라 **소리로** 후킹하게 기준을 잡았습니다.

주 2개는 **롱폼 1 + 쇼츠 1** 로 배분했습니다. 한 달 해보고 쇼츠에서만 구독이 붙으면
쇼츠 2개로 바꾸세요 — `AI_COMPANY.md` 0장 표만 고치면 됩니다.

## 자주 나오는 질문

**Q. 부서 12개가 다 필요한가요?**
아니요. 지금은 **1 · 3 · 4 · 5 · 6 · 7 · 10 · 12번** 여덟 개만 쓰시면 됩니다.
8번(협업) · 9번(정산) · 11번(자동화)은 제휴 메일이 오거나 수익이 생기면 그때 부르세요.

**Q. AI가 라이선스 괜찮다고 하면 믿어도 되나요?**
아니요. 그렇게 말하지 않게 막아뒀습니다. `⚠️ 라이선스 대표 확인 필요` 로만 올라옵니다.

**Q. 제목이 자꾸 비슷하게 나와요.**

**Q. 부서를 몇 개까지 늘려도 되나요?**
늘리는 것보다 **비우는 게** 어렵습니다. 2주 동안 한 번도 안 부른 부서는 지우세요.
