## 시작하기 · 30분

### STEP 1. 빈칸 채우기

`AI_COMPANY.md` 를 열고 **`[[ ]]` 표시된 곳**만 채우세요. 그게 전부입니다.

**0장(대표 정보)과 3장(금칙어)만 채워도 굴러갑니다.**
부서 12개를 다 채우려 하지 마세요. 처음엔 **1 · 3 · 4 · 5 · 12번 다섯 개**면 충분합니다.

### STEP 2. Claude Code 열고 첫 지시

이 폴더에서 `claude` 를 실행한 다음, 그대로 복붙하세요.

```
AI_COMPANY.md를 읽어줘.
지금부터 너는 이 회사의 직원들이야.
읽고 나서, 내가 채워야 할 빈칸이 어디인지 먼저 알려줘.
```

### STEP 3. 부서 채우기 (AI한테 시켜도 됩니다)

```
AI_COMPANY.md의 부서를 내 채널 기준으로 채워줘.
내 채널은 [주제]를 다루고, 주 시청자는 [타깃]이야.
부서마다 '지켜야 할 기준' 3줄은 반드시 반려 기준으로 써줘.
```

### STEP 4. 매일 아침 이 한 줄

```
/today
```

조사 → 기획 → 검수까지 돌고 **TOP 3만 보고하고 멈춥니다.**
대본은 대표가 1개를 고른 뒤에 씁니다. 이게 이 구조의 핵심이에요.

### STEP 5. 부서 하나만 부르고 싶을 때

```
/qa   [원고 붙여넣기]
/dept 이미지 제작팀   승인된 대본으로 캐러셀 8장 구성해줘
/report
```

---

## 슬래시 명령 4개

| 명령 | 하는 일 |
| --- | --- |
| `/today` | 조사 → 기획 → 검수 → **TOP 3 보고 후 정지** |
| `/qa` | 검수팀만 호출. 원고 반려 검사 (고쳐주지 않고 반려 사유만) |
| `/dept` | 부서 하나만 호출. 예) `/dept 정산팀 이번 달 미수금 정리해줘` |
| `/report` | 비서실 호출. 오늘 한 일을 일일 보고로 정리 + 기록에 저장 |

Claude Code 없어도 똑같이 돌아갑니다.
대화창에 `AI_COMPANY.md` 내용을 **통째로 붙여넣고** 이렇게 말하세요.


매번 붙여넣기 귀찮아지면 그때 Claude Code로 넘어오시면 됩니다.

---

## 왜 이렇게 나누나

AI한테 "인스타 콘텐츠 만들어줘"라고 하면 결과가 늘 애매합니다.
**한 명한테 조사·기획·검수·글쓰기·제작을 다 시켰기 때문**이에요.

| 쪼개기 전 | 쪼갠 후 |
| --- | --- |
| "콘텐츠 만들어줘" → 뭉뚱그린 결과 | "시장조사팀으로 일해줘" → 출처까지 붙은 후보 5개 |
| 내가 매번 처음부터 설명 | 부서 문서에 이미 기준이 적혀 있음 |
| 잘 나온 이유를 모름 | 어느 단계에서 좋아졌는지 보임 |
| 내가 다 검수 | 검수 담당 부서가 먼저 걸러냄 |

## 안전 규칙 6줄 ⚠️

`AI_COMPANY.md` 맨 위에 박혀 있고, `CLAUDE.md` 를 통해 매번 적용됩니다.

```
① 메일 실제 발송 금지 — 초안까지만
② SNS 실제 게시 금지 — 예약·업로드는 사람이
③ 결제·구독 금지
④ 원본 파일 삭제·덮어쓰기 금지 — 복제본에만 작업
⑤ 연결 안 된 서비스를 '완료'라고 보고 금지
⑥ 확인 안 된 정보를 사실처럼 쓰기 금지 — 출처 없으면 '미확인'이라고 표시
```

**⑤번이 진짜 중요합니다.** 이거 없으면 AI가 "인스타 업로드 완료했습니다"라고 말합니다. 안 했는데요.

## 자주 나오는 질문

**Q. 부서를 12개나 만들면 헷갈리지 않나요?**
헷갈립니다. 그래서 12번 비서실이 있어요. 저는 `/report` 보고만 봅니다.

**Q. AI가 제 말투를 못 따라 해요.**
`AI_COMPANY.md` 3장에 **금칙어**를 적으세요. "이렇게 써줘"보다 **"이건 쓰지 마"**가 훨씬 잘 먹힙니다.

**Q. 부서를 몇 개까지 늘려도 되나요?**
늘리는 것보다 **비우는 게** 어렵습니다. 2주 동안 한 번도 안 부른 부서는 지우세요.

**Q. 이거 만드는 데 얼마나 걸려요?**
빈칸 채우는 데 30분. 그날부터 씁니다. 나머지는 쓰면서 고쳐요.
