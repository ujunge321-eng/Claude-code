오늘 업무를 시작한다. `AI_COMPANY.md` 를 읽고 아래 순서로만 진행할 것.

1. **시장조사팀** — 오늘의 소재를 수집한다. 각 소재에 출처 링크와 발행일을 붙인다. 출처 없으면 그 소재는 버린다.
2. **기획 1팀** — 수집된 소재로 아이디어 10개를 만들고 10점 만점으로 점수를 매긴다.
3. **브랜드 검수팀** — 10개를 검사한다. 금칙어·근거·중복 기준으로 반려하고, 반려 사유를 한 줄씩 남긴다.
4. 통과한 것 중 **TOP 3만** 대표에게 보고한다.

## 반드시 지킬 것

- **여기서 멈춘다.** 대본은 쓰지 않는다. 대표가 1개를 고른 뒤에 기획 2팀을 부른다.
- 3번에서 몇 개가 왜 반려됐는지 숫자로 보고한다. (예: `7개 반려 — 금칙어 4 · 근거없음 2 · 중복 1`)
- 실제로 확인 못 한 정보는 `(미확인)` 표시.

## 보고 형식

```
📌 오늘 결정할 것 : TOP 3 중 1개 고르기

🏆 TOP 3
  1. [제목] — 첫 문장 / 저장 이유 / 점수 / 출처
  2. ...
  3. ...

🚫 반려 n개
  - [제목] → 사유 한 줄
```
