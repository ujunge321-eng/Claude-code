## 1. 사규 충돌 — 먼저 정리해야 할 것

현재 사규(`AI_COMPANY.md`)의 채널은 **JennyDream · 로파이 음악**입니다.
드라마는 같은 채널에 올릴 수 있는 포맷이 아닙니다.

| | 로파이 채널 | 드라마 |
| --- | --- | --- |
| 시청자 행동 | 틀어놓고 화면을 안 봄 | 화면을 봄 |
| 성공 조건 | 끄지 않게 하기 | 끝까지 보게 하기 |
| 구독 이유 | 일관된 무드 | 다음 편이 궁금함 |
| 제작 단위 | 트랙 + 루프 1장 | 컷 수십 개 + 대사 + 캐릭터 |

**같은 채널에 섞으면 로파이 쪽 구독 전환이 깨집니다.** 사규 2장 특수성 ②번
("구독은 곡이 아니라 채널을 보고 누른다")과 정면으로 부딪힙니다.

→ **대표 결정 필요 : 새 채널로 갈지, JennyDream 안에서 갈지.**
결정 전까지 아래는 전부 "새 채널 전제"로 읽어주세요.

## 2. AI 드라마 제작 파이프라인 (실제 실행 순서)

AI로 드라마를 만들 때 순서를 틀리면 뒤에서 전부 다시 만들게 됩니다.
아래 순서가 재작업을 가장 적게 만듭니다.

```
① 포맷 확정      세로 60초? 세로 3분 연속물? 가로 10분 단편?
      ↓
② 로그라인 1줄   "누가 / 뭘 원하는데 / 뭐가 막는가"
      ↓
③ 캐릭터 시트    ★ 여기서 얼굴을 고정한다. 건너뛰면 전부 무너짐
      ↓
④ 씬 리스트      씬 = 장소 1개 + 시간 1개. 씬마다 목적 한 줄
      ↓
⑤ 샷 리스트      컷 단위. 컷마다 [화면 / 대사 / 길이(초)]
      ↓
⑥ 스틸 생성      컷마다 정지 이미지 먼저. 영상보다 싸고 빠르게 검수됨
      ↓
⑦ 영상 생성      승인된 스틸만 image-to-video 로 움직임
      ↓
⑧ 사운드         목소리 → 효과음 → 음악 순. 반대로 하면 다시 함
      ↓
⑨ 편집·자막      컷 붙이고 자막. 여기서 처음 "드라마"가 됨
```

**③번을 건너뛰는 게 AI 드라마 실패의 1순위 원인입니다.**
캐릭터 시트 없이 컷마다 프롬프트를 새로 쓰면, 같은 인물이 컷마다 다른 사람이 됩니다.

---

## 3. 가장 많이 깨지는 지점 3개

### ① 캐릭터가 컷마다 다른 사람이 된다

- 원인 : 텍스트 프롬프트만으로 인물을 매번 새로 생성
- 해결 : **캐릭터 시트(정면·측면·표정)를 먼저 만들고, 그 이미지를 레퍼런스로 물려서** 컷을 생성
- 검수 기준 : 컷 10개를 나란히 놓고 봤을 때 같은 사람으로 안 읽히면 반려

### ② 컷이 길어서 화면이 무너진다

- 원인 : AI 영상은 길어질수록 손·얼굴·배경이 망가짐
- 해결 : **컷 하나를 3~5초로 끊는다.** 긴 장면은 컷을 나눠서 붙임
- 검수 기준 : 5초 넘는 컷은 반려. 나눠서 다시

### ③ 목소리와 입이 안 맞는다

- 원인 : 영상 먼저 만들고 목소리를 나중에 얹음
- 해결 : **대사 오디오를 먼저 뽑고**, 그 길이에 맞춰 컷 길이를 정함
- 대안 : 대사를 화면 밖(내레이션·전화·문자)으로 빼면 입 모양 문제가 사라짐 — 초반엔 이게 현실적

## 4. 저작권 게이트 (사규 2장 적용)

드라마는 로파이보다 걸릴 구멍이 많습니다. 소재를 올릴 때 아래를 **같이** 적습니다.

| 소재 | 확인할 것 |
| --- | --- |
| 배경음악 | 상업 이용 + **수익화** 가능 여부. "무료"만 적힌 건 자동 반려 |
| 효과음 | 출처 URL · 크레딧 표기 문구 |
| AI 목소리 | 실존 인물 목소리 학습본이면 반려. 상업 이용 약관 확인 |
| AI 생성 화면 | 사용한 툴의 **상업 이용 조건** |
| 원작 각색 | 웹툰·소설·드라마 기반이면 자동 반려 (2차 창작) |
| 얼굴 | 실존 인물을 닮게 만들면 반려 |

```
⚠️ 라이선스 대표 확인 필요 — AI는 "써도 됩니다"라고 판단하지 않습니다 (사규 9장)
```

## 5. TOP 3 진입 방향

사규 3장 결정 게이트에 따라 **후보 3개까지만** 올립니다. 고르는 건 대표님입니다.

### 안 A. 세로 숏폼 연속극 (편당 60초 · 주 3편)

- 만드는 법 : 컷 12~15개 / 대사는 내레이션·문자 위주 / 매 편 끝에 다음 편 훅
- 장점 : **입 모양 문제를 피할 수 있음.** 제작량이 적어 1인 운영 가능
- 단점 : 매 편 훅이 약하면 2편에서 전부 이탈
- 필요한 것 : 캐릭터 2명 · 배경 3곳

### 안 B. 가로 단편 1화 완결 (편당 5~8분 · 주 1편)

- 만드는 법 : 씬 5~6개 / 컷 60~80개 / 내레이션 중심
- 장점 : 완결이라 이탈 부담이 적고, 한 편이 포트폴리오가 됨
- 단점 : 제작량이 안 A의 4~5배
- 필요한 것 : 캐릭터 3명 · 배경 6곳

### 안 C. 대사 없는 무성 드라마 (편당 90초 · 주 2편)

- 만드는 법 : 대사 0 / 음악과 표정으로만 전개 / 자막 최소
- 장점 : **입 모양·목소리 문제가 통째로 사라짐.** 언어 장벽 없음 → 해외 유입
- 단점 : 이야기가 단순해야 함. 복잡한 서사 불가
- 필요한 것 : 캐릭터 1~2명 · 배경 2곳

> 지금 인력(1인 + AI) 기준으로는 **안 A 또는 안 C가 현실적**입니다.
> 안 B는 1편 만들고 지쳐서 멈추는 경우가 가장 많습니다.
